# video-files

Репозиторий для хранения видеофайлов с использованием Git LFS.

## Отслеживаемые форматы

Через Git LFS отслеживаются: `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm`, `.wmv`, `.flv`, `.m4v`, `.mpg`, `.mpeg`.

## Использование

```bash
git lfs install
git add <файл>
git commit -m "add video"
git push
```
